# ContaBanco

Este é um programa Java simples que interage com o usuário via terminal para coletar informações sobre uma conta bancária e, em seguida, exibe uma mensagem de boas-vindas com os detalhes fornecidos.

## Funcionalidades

O programa realiza as seguintes ações:

1.  Solicita ao usuário que digite o nome do cliente.
2.  Solicita o número da agência.
3.  Solicita o número da conta.
4.  Solicita o saldo inicial da conta.
5.  Exibe uma mensagem de boas-vindas personalizada com as informações da conta fornecidas.

## Como executar

Para executar este programa, você precisará ter o Java Development Kit (JDK) instalado em seu sistema. Siga estes passos:

1.  **Salve o código:** Salve o código Java em um arquivo chamado `ContaBanco.java`.
2.  **Compile o código:** Abra o terminal ou prompt de comando, navegue até o diretório onde você salvou o arquivo e execute o seguinte comando para compilar o código:
    ```bash
    javac ContaBanco.java
    ```
    Isso irá gerar um arquivo chamado `ContaBanco.class`.
3.  **Execute o programa:** No mesmo terminal, execute o programa com o seguinte comando:
    ```bash
    java ContaBanco
    ```
    O programa então solicitará que você insira as informações da conta passo a passo.
