
# Formação Java - DIO

**Formação Java** é um curso completo oferecido pela [DIO](https://www.dio.me/) com o objetivo de ensinar Java do zero até o desenvolvimento de aplicações robustas com **Spring Framework**, uma das ferramentas mais utilizadas no mercado profissional.

## 🚀 Objetivo da Formação

Capacitar os alunos em **Java** desde os fundamentos da linguagem até conceitos avançados, como **Programação Orientada a Objetos (POO)** e **desenvolvimento de aplicações com Spring Framework**, preparando-os para atuar em projetos reais e construir um portfólio de alto nível.

---

## 📚 Estrutura da Formação

A formação é dividida em **módulos progressivos**, começando com os fundamentos e avançando para tecnologias modernas:

### Módulos Iniciais
- Fundamentos da linguagem Java
- Lógica de Programação
- Programação Orientada a Objetos (POO)

### Módulos Avançados
- Desenvolvimento de aplicações com Spring Framework
- Projetos práticos com Java
- Preparação para o mercado com boas práticas e padrões de projeto

---

## 🎯 Atividades Práticas

- **Desafio de Código**  
  Teste seus conhecimentos resolvendo problemas com Java diretamente na plataforma.

- **Desafio de Projeto**  
  Construa aplicações completas e reais para adicionar ao seu portfólio.

---

## 🧰 Ferramentas de Aprendizado

- **Fórum**  
  Tire dúvidas e compartilhe conhecimento com a comunidade.

- **Rooms**  
  Converse com outros alunos e aumente seu networking.

- **Lista de Matriculados**  
  Veja quem está estudando com você e acompanhe sua jornada.

- **Certificados**  
  Ao concluir os módulos, receba certificados de conclusão que comprovam seu conhecimento.

---

## ✅ Pré-requisitos

- Conhecimentos básicos de **Lógica de Programação**
- Familiaridade com **Pensamento Computacional**

---

## 🏁 Ao final da formação, você será capaz de:

- Criar aplicações robustas com Java e Spring Framework
- Desenvolver APIs e sistemas orientados a objetos
- Trabalhar com boas práticas de código e arquitetura
- Montar um portfólio profissional com projetos reais
